## Description

Urgent recall messages can be fake—or describe a real recall while substituting an unsafe action channel. NoticeProof verifies the particular notice against authoritative evidence, switches the consumer to an independently verified contact, and tracks the remedy without asking an LLM to decide what is true.

Live app: https://lovely-eel-809.convex.site

Source: https://github.com/tang-vu/noticeproof

Convex runs the typed realtime case state machine, storage, schedulers, webhooks, approvals, timelines, and receipts. OpenAI structures claims and produces bounded rule-grounded explanations. Firecrawl acquires current CPSC and authority-linked manufacturer evidence. AgentMail receives forwarded notices and starts a new trusted thread only after explicit approval.

NoticeProof currently focuses on U.S. CPSC consumer-product recalls. It is not affiliated with CPSC or any manufacturer, does not provide legal advice, and never treats missing evidence as proof of safety.
