## Primary post

Urgent recall messages can be fake—or describe a real recall while sending you through the wrong door.

I built **NoticeProof**: forward a recall notice, verify each claim against authoritative evidence, block unsafe channels, and start a human-approved thread with an independently verified contact.

The key verdict: **Real recall. Unsafe channel.**

Convex runs the realtime state machine and evidence record. OpenAI structures claims and selects bounded explanations. Firecrawl acquires changing official evidence. AgentMail receives the notice and switches the consumer to a trusted thread.
